# Array Manipulation Algorithms

This directory contains techniques and algorithms for working with 1D arrays:

| Problem / Technique | Directory | Description | Time Complexity | Space Complexity |
|---|---|---|---|---|
| **Largest Unique Subarray** | `Largest-Unique-subarray/` | Finds the maximum length contiguous subarray containing all unique elements (sliding window). | $O(n)$ | $O(n)$ |
| **Maximum Product Subarray** | `maximum-product-of-the-array/` | Finds the maximum product of a contiguous subarray using forward and backward prefix product passes. | $O(n)$ | $O(1)$ |
