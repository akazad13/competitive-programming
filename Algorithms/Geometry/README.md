# Computational Geometry

This directory contains fundamental computational geometry algorithms and primitives:

| Algorithm / Problem | File | Description | Complexity |
|---|---|---|---|
| **Polygon Area (Shoelace Formula)** | `area-of-a-polygoan/areaofpoly.cpp` | Computes the area of an $N$-vertex non-self-intersecting polygon. | $O(N)$ time, $O(1)$ space |
| **Line Segment Intersection** | `area-of-a-polygoan/2 line intersection check.cpp` | Checks if two 2D line segments intersect using cross-product orientation test. | $O(1)$ time, $O(1)$ space |
| **Closest Pair of Points** | `area-of-a-polygoan/line swipping closest point.cpp` | Finds the minimum distance between $N$ points in 2D using sweep-line technique. | $O(N \log N)$ time, $O(N)$ space |
