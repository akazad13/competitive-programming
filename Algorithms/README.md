# Algorithms

This directory contains implementations of algorithmic paradigms and techniques categorized by domain:

## Categories

| Category | Directory | Description |
|---|---|---|
| **Array Manipulation** | [`Array-Manipulation/`](Array-Manipulation/) | Two-pointer, sliding window, and subarray techniques (Longest Unique Subarray, Max Product Subarray). |
| **Backtracking** | [`Backtracking/`](Backtracking/) | Combinatorial search and constraint satisfaction (N-Queens, M-Coloring). |
| **Dynamic Programming** | [`Dynamic-Programming/`](Dynamic-Programming/) | Memoization, tabular DP, bitmask DP, digit DP, and 2D submatrix optimization. |
| **Computational Geometry** | [`Geometry/`](Geometry/) | Shoelace polygon area, 2D line segment intersection, and closest pair sweep-line. |
| **Graph Theory** | [`Graph-Theory/`](Graph-Theory/) | BFS, DFS, Dijkstra, Bellman-Ford, Floyd-Warshall, Kruskal, Prim, DSU, Articulation Points, Bridges, SCC, 2-SAT, Dinic / Edmonds-Karp Max Flow, Heavy-Light Decomposition. |
| **Sorting** | [`Sorting/`](Sorting/) | Counting Sort, Radix Sort, Merge Sort, Quick Sort, and Heap Sort with test cases. |
| **String Processing** | [`String-Processing/`](String-Processing/) | KMP, Z-Algorithm, Rabin-Karp Hash, Trie (Array & Pointer), LCS, Palindromes, and Lexicographically Smallest Rotation. |
